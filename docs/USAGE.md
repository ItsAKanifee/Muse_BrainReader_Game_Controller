Usage
=====

Running examples
----------------

- A simple entrypoint is `Main.py`. Run it with:

```
python Main.py
```

- Many of the example games live under `Game_Folder/`. To run a specific example, run its top-level script, for example:

```
python Game_Folder/Jumpy_Bird.py
```

Muse reader
-----------

- The Muse-related scripts and helpers are in `Muse_Reader_Assets/`. Inspect `Muse_Reader_Assets/Reader.py` and `Calibrate.py` for usage examples.

Troubleshooting
---------------

- If you see missing module errors, install the missing package into your virtual environment.
- For LSL/Muse connectivity issues, verify headset drivers and network setup required by your Muse device.
